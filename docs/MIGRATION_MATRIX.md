# Feature ownership and migration matrix

Each row names a current behavioral boundary and its acceptance condition. **Shared** means an implementation exists in common Kotlin. **Retain native** means a platform responsibility. **Transition** means the Swift implementation still serves callers. **Gap** identifies work needed before switching. **Retirement candidate** requires proof of replacement and a consumer search before deletion.

| Feature and existing Swift boundary | Shared counterpart and current owner | Migration and verification gate |
| --- | --- | --- |
| App assembly and orchestration. `BannerAppEnvironment.shared`, `AppOrchestration.keepEventChannelsCurrent`, `refreshFantasyContexts` | **Retain native.** One optional app-scoped foundation host joins the existing composition root | Confirm phone and CarPlay share one playback controller and sports host. Keep lifecycle and preference observation native |
| NHL scores. `SportsRepository.legacyScoreboard`, `NHLProvider.scores(on:)` | **Shared on enabled route.** `AppleNhlDiscovery.scores` → `NativeHockeyProvider.scores`. Swift projection restores legacy numeric IDs, canonical IDs and bundled crests | Compare fixture scores, clock running state, intermission suppression, periods, venue, broadcast names, historical game navigation and stale/error states. Run the Xcode live test before changing the default |
| NHL schedule. `legacyScoreboards`, `cachedLegacyScoreboards`, `NHLProvider.schedule` | **Shared on enabled route.** `NativeHockeyProvider.schedule` owns weekly fetches, date-window filtering, deduplication and the current-day scoreboard overlay | Check historical schedule, local-midnight boundaries and current-day replacement. Wider requests are split into adjacent calendar windows, deduplicated by provider game identity and sorted |
| NHL teams and rosters. `NHLProvider.teams`, `standings`, `roster`, `playerOverview` | **Transition.** Same operations exist in `NativeHockeyProvider`. Numeric roster discovery reuses the selected score source | Preserve old numeric team/player IDs and canonical lookup. Verify historical-team abbreviation fallback, divisions, shots, win percentage and roster grouping |
| NHL detail. `enrichedLegacyMatch`, `legacyGameSummary`, `NHLGameCenterService.fetch`, `NHLGameCenterReducer.apply` | **Transition.** `NativeHockey`, event mapping, reducers and snapshots exist. Apple still owns its detail loader | Compare landing/box/PBP/right-rail updates, missing feeds, intermissions, goalies, event video and out-of-order updates. Keep detailed source owners separate from score discovery |
| MLB | **Transition.** `MLBProvider.scores/schedule` and MLB live-feed/box readers overlap `NativeBaseballProvider`, `NativeBaseball` and extras caches | Compare gamePk, inning/half, outs/bases, probable pitchers, highlights, probability and rescheduled games |
| NFL | **Transition.** `NFLProvider.scores/schedule/injuries`, Shield token/config, week/calendar and drives overlap `NativeFootballProvider`, `NativeFootball`, `NflCalendar` | Test by season/week/type, preseason and playoffs. Compare drive/play IDs, bearer refresh, injuries and denial cooldowns. Preserve old connection IDs |
| NBA and WNBA | **Transition.** Separate native league clients and Game Centre mapping overlap `NativeBasketballClient`, `NativeBasketballProvider`, reducers and snapshots | Compare each league independently. Preserve leading-zero game IDs, regulation duration, overtime, rosters and boxscores |
| EPL and MLS | **Transition.** `EPLProvider` SDP and `MLSProvider` Sportec fixtures, lineups, commentary and standings overlap `NativePremierLeagueProvider` and `NativeMlsProvider` | Compare kickoff timezone, stoppage time, abandoned fixtures, stable fixture IDs, commentary pagination and recovery |
| LaLiga and UCL | **Transition.** Apple LaLiga official/FotMob enrichment overlaps `NativeLaLiga` mapping, authority and reconciliation. Champions League uses FotMob competition 42 | Verify cross-provider IDs and cooldowns with pinned fixtures. Reject wrong competitions. Preserve unavailable detail states |
| CFL | **Shared available, discovery restricted.** KMP Echo/PIMS and leaders exist. Swift repository default provider list does not advertise CFL | Validate schedule/standings and watch matching before enabling the league picker. Detailed drives remain a gap |
| F1 | **Transition.** `F1Provider.scores/schedule/standings`, live session transport and archive handling overlap `F1Repository`, SignalR engine and timing state | Check session identity, archive replay, compressed frames, reconnects, silence timeout and authenticated failure on a real Apple transport |
| PGA | **Transition.** `PGAProvider.scores/schedule/standings`, tournament detail and golfer views overlap shared PGA GraphQL queries and repository | Compare tournament, cut, field, scorecard, gzip results and rotation of the public frontend configuration |
| ESPN fallback, news and player stats | **Gap/transition.** KMP supports capability-aware ESPN fallback. Swift `SportsRepository` explicitly rejects several unsupported capabilities and provides native player stats/news | Add per-capability source policy before expanding the generic bridge. NHL cutover selects the native NHL provider explicitly so ESPN IDs cannot leak into native navigation |
| Followed teams and settings | **Shared models, platform persistence.** Apple `PreferencesStore` and canonical identity resolver differ from Kotlin favourite/team keys | Introduce non-destructive aliases and round-trip old saved data. Compare canonical IDs, colours, missing logos, reorder and unfollow. This milestone performs no preference rewrite |
| Fantasy providers | **Transition.** `ESPNFantasyService.connect/leagues/matchup` vs `EspnFantasyApi.league` and its mappers. `SleeperFantasyService.connect/leagueUsers/leagueRosters/playerDirectory` vs `SleeperFantasyApi.account/season/leagues/load` | Add a Swift-facing facade, map league/team/roster identities, cookies and failure states. Preserve private ESPN sessions, cached directory and disconnect semantics |
| Fantasy simulation, scoring, contextual notifications | **Transition.** Shared `NativeFantasyEngine`, pool, fixtures and contexts overlap Apple fantasy rules. Native notification delivery remains Apple-owned | Compare drafts, categories, rosters, scoring overrides, fixture association and notification deduplication against saved leagues |
| Podcasts, news and odds | **Transition/retain native.** Shared RSS catalog, news ranking, team podcast resolver and odds mappers exist. Apple owns XML/audio/session/CarPlay handling | Compare team alias matching, feed URLs, editorial ranking and freshness. Verify signed Podcast Index discovery with newly provisioned credentials |
| TMDB discovery and metadata | **Shared available, enrichment gap.** `TmdbRepository.search/popular/browse/detail/episodes` covers discovery and verified external IDs. Apple `TMDBMetadataService.enrich/enrichSeason` also resolves provider items by IMDb or conservative title/year matching | Port and test confidence rules and provenance before replacing Swift enrichment. Preserve native provider metadata when no unambiguous match exists |
| Entertainment inventory | **Gap.** `EntertainmentRepository.sync/replace/markUnknown/classifyM3U/classifyM3USeries/channel` handles provider inventory, unknown availability and playable source association | Keep Swift catalog and AVPlayer source handoff. Add shared inventory/source contracts and fixtures for multiple playlists and removed/reappearing sources |
| Watchlist, progress and Continue Watching | **Transition.** Shared `MediaLibrary.toggle/record/merge` uses typed movie/episode IDs. Apple `watchProgress/record/toggleWatchlist/hideFromContinueWatching/markWatched` uses provider/canonical keys and retains history metadata | Need aliases, hidden items and history snapshots even for titles without TMDB IDs. Test preview/backups, duplicate sources, unknown duration, completed episodes and restoration before any write migration |
| Stremio add-ons | **Shared available.** `AddonLibrary`, `StremioClient` and `MediaPlaybackResolver`. Apple add-on Keychain adapter is prepared | Add Swift management/source UI and AVPlayer header/subtitle handoff. Exercise disabled providers, TLS, LAN prompts, cancellation, codec support and failed streams |
| Playlists and IPTV identity | **Gap.** Swift `PlaylistStore.load/migrateCredentialsIfNeeded/buildIndexes/refresh`, Xtream/M3U and existing Android `core` ingestion remain host-owned | Migrate bounded parsing and identity independently. Keep playlist UUIDs, stored credentials, channel IDs, backups and default playlist intact |
| Guide and stream matching | **Gap.** Swift `EPGRepository.buildCanonicalLineup/matchEPGChannels/mergeProgrammes/currentProgramme/requestXtreamEPGIfNeeded` spans indexes, custom XMLTV, per-channel top-ups and platform persistence. Android `CatalogMatcher`/guide loading remains in `core` | Compare provider-program time windows, guide IDs, TSN feed disambiguation, stale data, timezone/DST, cancellation and memory. Track provider EPG authority independently of optional metadata sources |
| Playback and system integrations | **Retain native.** AVPlayer/AVKit, CarPlay `playVerifiedGame/changeBroadcast`, Media3, native deep links, App Intents, Live Activities, StoreKit, notifications and widgets | Verify codec/header handling, background audio, stream restart, handoff, existing purchases, alerts and installed-app identities on devices |
| Sync and backup | **Retain native/transition.** `CloudSyncService.save/load/purgeLegacyStreamURLBlobs` is Apple iCloud preference state. Android has user-selected cloud-file export/import | Define a versioned portable file schema and read-only compatibility importer. Keep current sync behavior, exclude credentials and verify merge/rollback |
| Legacy retirement | **Conditional retirement candidates.** Swift NHL score/schedule request and mapping paths for the application only | Require green native comparison, proof of one active source, searches of standalone package/tests/extensions/background callers and device verification. No Swift provider implementation or its tests were deleted |

The immediate next migration is NHL teams/standings after the discovery gate passes. Followed identity and Game Centre require separate contracts. Fantasy, metadata and IPTV follow in that order.
