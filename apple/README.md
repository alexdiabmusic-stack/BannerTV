# BannerTV native Apple application

Open `Stadia TV.xcodeproj` here. The native SwiftUI app, AVPlayer, CarPlay, Live Activities, BannerSharedKit and original Apple tests are retained. The app has an opt-in NHL discovery route through the real Kotlin framework. Use the repository-root setup commands before building.
